  <name>Task 2: Move to src layout and delete old config files</name>
  <files>src/kotti/, src/kotti/__init__.py, setup.py, setup.cfg, MANIFEST.in, pytest.ini, tox.ini</files>
  <action>
Execute the following steps in order. Each logical step should be a separate git commit for reviewable history.

**Commit 1 — src layout move (preserves git history):**
```bash
mkdir -p src
git mv kotti/ src/kotti/
```
This single `git mv` preserves file history. Do NOT copy-and-delete.

**Commit 2 — delete old config files:**
```bash
git rm setup.py setup.cfg MANIFEST.in pytest.ini tox.ini
```
Also delete `.coveragerc` if it exists (coverage config should be in pyproject.toml or removed). Check: `ls .coveragerc 2>/dev/null` — if present, `git rm .coveragerc`.

**After both commits — reinstall editable:**
```bash
uv pip install -e ".[dev]"
```
This is CRITICAL. Without reinstall, Python's `.pth` file still points to the old `kotti/` location. The stale editable install is the #1 pitfall in src layout migrations.

**Verify the install resolved correctly:**
```bash
python -c "import kotti; print(kotti.__file__)"
```
Output MUST contain `/src/kotti/`. If it does not, the editable install is stale — uninstall and reinstall:
```bash
uv pip uninstall kotti && uv pip install -e ".[dev]"
```

**Important:** The src layout move commits (1 and 2) must NOT modify any Python source code — keeping the move commit free of code changes makes review trivial.

**Commit 3 — add `kotti.__version__` via importlib.metadata:**

This implements the locked user decision from CONTEXT.md: "`kotti.__version__` exposed at runtime via `importlib.metadata.version("kotti")` for backwards compatibility."

Add the following block to the **top** of `src/kotti/__init__.py` (before existing imports):

```python
from importlib.metadata import version as _version
from importlib.metadata import PackageNotFoundError as _PNF

try:
    __version__ = _version("Kotti")
except _PNF:
    __version__ = "unknown"
```

Do NOT remove the existing `get_version()` function or any `pkg_resources` usage — that replacement is Phase 2 (DEP-04, DEP-05). This commit only **adds** the new `__version__` attribute.
